📊 Customer Behavior & Purchase Analysis

📌 Project Overview

Customer Behavior & Purchase Analysis is an interactive Power BI project developed to analyze customer purchasing patterns, sales performance, product performance, payment preferences, order status, and sales trends.

The dashboard transforms raw purchase data into meaningful business insights through interactive visualizations, KPIs, slicers, drillthrough, bookmarks, and page navigation.

---

🎯 Project Objectives

- Analyze overall sales and order performance
- Understand customer purchasing behavior
- Identify customer segments and purchasing patterns
- Analyze product and category performance
- Understand customer payment preferences
- Analyze order status and order trends
- Identify monthly sales and quantity trends

---

🛠️ Tools & Technologies

- Power BI – Dashboard development and visualization
- Power Query – Data cleaning and transformation
- DAX – Measures and calculations
- CSV – Source dataset
- GitHub – Project documentation and version management

⚙️ Power BI Features Used

🔹 Page Navigation

A navigation menu allows users to move between dashboard pages easily.

🔹 Slicers

Interactive slicers allow users to filter the dashboard based on different business dimensions.

🔹 Bookmarks

Bookmarks are used to create interactive dashboard views and navigation experiences.

🔹 Drillthrough

Drillthrough allows users to move from summary-level analysis to detailed customer or purchase information.

🔹 DAX

DAX measures are used to calculate important business metrics such as sales, orders, customers, quantity, and average order value.
